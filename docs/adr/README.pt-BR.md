# Architecture Decision Records

[English](./README.md)

Este diretório armazena decisões arquiteturais importantes.

## Como criar uma nova ADR

1. Copie `template.md`.
2. Nomeie o arquivo com o prefixo `ADR-XXXX-...`.
3. Atualize este índice.

## Índice

- `ADR-0001`: Stack inicial e princípios de engenharia
- `ADR-0002`: Posicionar o VeraBrain como extensão do Hermes
- `ADR-0003`: Revisar o stack de implementação para um VeraBrain
  centrado no Hermes
- `ADR-0004`: Retirar o scaffold temporário de TypeScript e Node do
  repositório
- `ADR-0005`: Adotar uma arquitetura de persistência com Postgres e
  pgvector
- `ADR-0006`: Estabelecer os limites da política de retrieval do
  VeraBrain
- `ADR-0007`: Definir o modelo de ferramentas do VeraBrain
