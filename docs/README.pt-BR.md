# Documentação

[English](./README.md)

Este diretório contém decisões de arquitetura, evidências de release e
outros documentos duráveis do projeto.

## Estrutura

- `docs/domain/`: Documentos conceituais e de modelo de domínio
- `docs/adr/`: Architecture Decision Records
- `docs/runbooks/`: Runbooks práticos para caminhos locais e operacionais
- `docs/releases/`: Evidências de release e notas associadas

## Regra bilíngue

- Os documentos em inglês são a fonte padrão.
- Cada documento relevante em inglês dentro de `docs/` deve ter um
  espelho sincronizado em `pt-BR` ao lado.
- Qualquer mudança em documento bilíngue deve atualizar as duas versões
  no mesmo slice.
