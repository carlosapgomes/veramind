# Bilingual Documentation Governance

## Why

The repository currently mixes Portuguese and English across its main
artifacts, which weakens consistency and makes onboarding harder.

The project also lacks an explicit rule that requires bilingual
documentation pairs to stay synchronized when one side changes.

## What Changes

- Standardize normative project artifacts on American English
- Mirror `README.md` and relevant `docs/` documents in Brazilian
  Portuguese
- Add top-of-file language links between each bilingual document pair
- Record synchronization rules in the workflow and quality bar

## Impact

- Improves consistency for contributors and external readers
- Keeps English as the default source of truth for documentation
- Makes bilingual maintenance an explicit repository obligation
